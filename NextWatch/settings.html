Preferences

LANGUAGE

Application language

Language applied to the entire application, only English has silly stuff.

PLAYBACK

Autoplay

Automatically play the next episode in a series after reaching the end. Can be enabled by users with the browser extension, a custom proxy, or with the default setup allowed by the host.

Skip end credits

When enabled, automatically play the next episode at 99% completion to skip end credits. When disabled, wait until the episode is fully completed.

Auto skip segments

When enabled, auto skip intro, recap, and preview segments while watching.

Low performance mode

Optimizes the application for slower connections and devices by disabling bandwidth-heavy features. This mode reduces data usage and improves the core app's watch functionality intact.

Manual source selection

Require picking a source before scraping. Disables automatic source selection and opens the source picker when starting playback.

Preferred minimum resolution

When auto-selecting sources, keep checking working sources until this quality level is met. If unavailable, the best working source is used.

Auto resume on playback error

Automatically continue searching for other sources when the current source fails during playback. If disabled, you'll see an error screen with a manual resume option.

Last used source

Automatically prioritize the source that successfully provided content the previous time. This helps ensure continuity when watching series.

Custom source order

Drag and drop to reorder sources. This will determine the order in which sources are checked for the media you are trying to watch. If a source is greyed out, it means the extension is required for that source.
(The default order is best for most users)

PLAYER CONTROLS

Enable hold to boost

Hold spacebar or touch and hold the screen to temporarily increase playback speed to 2x. Release to return to previous speed.

Enable double tap to seek

Tap on the left or right side of the player to seek 10 seconds forward or backward.

Enable controller support

Keyboard Shortcuts

Customize the keyboard shortcuts for the application. Hold ' to show this help anytime

EXPERIMENTAL

Auto subtitle syncing

Automatically aligns the subtitle audio by analyzing speech while you watch, correcting out-of-sync subtitles with manual adjustment. May not work on every source.
